# Proyecto de Análisis de Expresión Génica de Datos de Secuenciación de ARN
**Objetivo general:** Analizar datos de RNA-Seq para identificar diferencias de expresión génica entre dos condiciones experimentales mediante un flujo de trabajo reproducible.
**Objetivos específicos:**

1. Organizar y validar los datos de expresión procedentes de RNA-Seq.
2. Normalizar los conteos génicos para realizar comparaciones entre muestras.
3. Identificar genes sobreexpresados y subexpresados entre grupos experimentales.
4. Aplicar análisis estadísticos mediante DESeq2.
5. Generar visualizaciones como PCA, gráficos de volcán, gráficos MA y mapas de calor.
6. Documentar los resultados mediante un procedimiento reproducible que pueda compartirse y mejorarse en GitHub.
